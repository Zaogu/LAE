================================================================================
运行方式
================================================================================
1. 激活环境：  conda activate sdvrpd
2. 安装依赖：  pip install -r demo/requirements.txt && pip check
3. 构建实例：  python demo/data/instance.py --force
4. 健康检查：  python demo/healthcheck.py
5. 单次求解：  python demo/solver/alns.py <instance.json>  （或 experiments/run_all.py）
6. 启动控制台：streamlit run demo/ui/app.py
